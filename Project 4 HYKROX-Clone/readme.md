# HYKROX Landing Page Clone

## 📌 Project Overview
This project is a landing page clone inspired by the HYKROX website. It is designed like a modern portfolio and focuses on clean UI, stylish layouts, and attractive frontend design using HTML and CSS.

---

## 📚 What You Will Learn
In this project, you will learn:

- How to create a modern landing page
- How to structure portfolio-style sections
- How to use CSS for professional UI design
- How to create responsive layouts
- How real-world landing pages are designed

---

## 🧪 Features of This Project
- Modern hero section
- Stylish navigation bar
- Portfolio-inspired layout
- Smooth section arrangement
- Attractive typography
- Responsive design structure
- Clean and modern user interface

---

## 🎨 CSS Concepts Used
- Flexbox
- CSS Positioning
- Hover Effects
- Background Styling
- Box Shadows
- Border Radius
- Spacing and Alignment
- Responsive Layout Techniques

---

---

## 🚀 How to Run the Project
1. Download or clone the project folder.
2. Open `index.html` in any web browser.
3. Make sure `style.css` is linked correctly.
4. Explore the landing page design and layout.

---

## 🛠️ Technologies Used
- HTML5
- CSS3
