# Registration Form Clone

## 📌 Project Overview
This project is a modern Registration Form Clone created using HTML and CSS. The goal of this project is to practice frontend form design, layout structuring, and UI styling by recreating a professional registration page.

---

## 📚 What You Will Learn
In this project, you will learn:

- How to build a registration form using HTML
- How to style forms using CSS
- How to organize form fields professionally
- How to improve user interface design
- How real-world signup pages are structured

---

## 🧪 Features of This Project
- Modern registration form UI
- User input fields
- Email and password section
- Responsive form layout
- Stylish submit button
- Clean and user-friendly interface
- Professional form structure

---

## 🎨 CSS Concepts Used
- Flexbox
- Box Shadow
- Border Radius
- Hover Effects
- Form Styling
- Padding and Margins
- Alignment and Spacing
- Responsive Design Basics

---


---

## 🚀 How to Run the Project
1. Download or clone the project folder.
2. Open `index.html` in your browser.
3. Make sure `style.css` is properly linked.
4. Explore the registration form UI and layout.

---

## 🛠️ Technologies Used
- HTML5
- CSS3

## 🎯 Learning Outcome

- How to structure user input sections
