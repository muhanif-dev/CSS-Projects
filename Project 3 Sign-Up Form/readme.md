📝 Modern Signup FormA sleek, responsive signup form built primarily with CSS to practice layout techniques, styling, and UI/UX best practices.
✨ FeaturesFully Responsive:
Optimized for mobile, tablet, and desktop screens.
Modern UI: Features a minimalist design with custom typography and subtle shadows.
Interactive States: Includes :hover, :focus, and :active states for form inputs and buttons.
Glassmorphism: Stylish frosted-glass effect on the form container.Client-side Validation: Basic HTML5 validation for email and password fields.
🛠️ Built WithHTML5 - Semantic structure.CSS3 - Flexbox/Grid, custom properties (variables), and animations.Google Fonts - Montserrat or Poppins.
🧠 What I Learned
Mastering CSS Flexbox for centering elements.Implementing Custom Form Styling to override default browser appearances.Using CSS Variables for consistent color schemes across the project.
